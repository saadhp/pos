Allows POS managers to assign non-cash payment methods to Point of Sale
configurations even while sessions are currently open:

- Permits adding non-cash payment methods from POS Settings, Payment
  Method form, or the batch assignment wizard during open sessions.
- Preserves Odoo safety checks: cash payment methods cannot be added and
  existing payment methods cannot be removed while a session is open.
- Logs each live assignment on the open session chatter and pushes a
  WebSocket event so active POS screens refresh payment methods without
  reloading.

Usage
=====

1. Open *Point of Sale > Configuration > Payment Methods* and select a
   non-cash payment method.
2. Click *Assign to POS* to link it to one or more POS configurations
   (including ones with open sessions), or add it directly from *Point
   of Sale > Configuration > Settings*.
3. Active cashier sessions receive the new payment method automatically
   and log the change in the session chatter.
